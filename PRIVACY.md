# Mobius 3D privacy

Last updated 8 October 2026.

**Mobius 3D collects nothing.** It has no account, no analytics, no ads and no
telemetry, and it sends nothing about you or your files anywhere.

- **Your models stay on your computer.** Files you open are read on your own
  machine and are never uploaded. The viewer blocks every network request a
  model makes (a texture pointing at a web address, for example), so nothing a
  file references can reach the internet.
- **Settings** (accent colour, view options) are kept on your own computer.
- **Updates.** The Microsoft Store copy is updated by the Store and makes no
  network requests of its own. The copy installed from GitHub checks this
  repository's Releases for a newer version at launch; GitHub sees that request
  as it sees any download.
- **The web preview** at dexcimino.com/mobius works the same way: files are
  read in your browser and never sent to the site.

Questions: open an issue at https://github.com/dexdcimino/mobius-3d/issues.
